1. EXECUTIVE SUMMARY & TRACK 01 ALIGNMENT
--------------------------------------------------------------------------------
AgentReady is an end-to-end Autonomous Commerce Readiness Platform built for the
Razorpay Buildathon Track 01.

Track 01 has two foundational pillars:
  1. "Grow the merchant's revenue" — achieved via the proactive AI Growth Agent,
     automated bundling with category-aware attach rates, and 90-day GMV simulation.
  2. "Make them sellable to AI buyers" — achieved via standardized AI manifests,
     trust scoring (0-100), multi-round counter-offer negotiation, protocol exports
     (ACP / schema.org), real-time WebSocket streaming, and a deterministic safety gate.

The platform bridges messy real-world merchant catalogs (Meesho, Amazon India,
Flipkart, Zomato, Blinkit, Nykaa, Tata CLiQ, Croma, boAt) and autonomous buyer agents,
allowing agents to discover, negotiate, and execute Razorpay payments under strict
merchant-defined financial boundaries.


2. WHAT WE HAVE BUILT (CHRONOLOGICAL & SYSTEM PROGRESSION)
--------------------------------------------------------------------------------
From inception to final build, the platform was developed across key milestones:

  A. Foundation & Safety Architecture:
     - Implemented a deterministic, pure-Python Policy Engine (services/policy_engine.py).
       Critical Invariant: LLMs NEVER touch money or order creation directly. All offers
       must pass through deterministic Python checks.
     - Hardened startup checks: live Razorpay keys are immediately rejected; only test keys
       (rzp_test_*) are accepted.
     - Implemented an append-only AuditLog database that writes before returning responses.

  B. Catalog Normalization & Trust Scoring:
     - Created catalog normalizer converting raw CSV/text into structured Product manifests.
     - Implemented 4-component Trust Scorer (Completeness 35%, Settlement Consistency 30%,
       Dispute Rate 20%, Freshness 15%).

  C. Real-World Authentic Merchants & Dynamic Ecosystem:
     - Populated verified catalogs with 12 authentic stores and 161 verified products:
       * Meesho Fashion Direct (Sarees, Anarkalis, Kurtis, Ethnic Wear)
       * Amazon India Official Hub (Electronics, Sony ANC headphones, iPads, Logitech)
       * Flipkart SuperComNet Sports (Nike Pegasus, Puma RS-X, Adidas Ultraboost)
       * Blinkit Instant Grocery, Zomato Daily, Nykaa Luxe, Tata CLiQ, Croma, boAt Lifestyle
     - Added real-time source web link integration so buyers can view live listings.

  D. Realtime Firebase Synchronization & Robust Auth:
     - Connected Firebase Realtime Database (agent-ray-default-rtdb) via Admin SDK.
     - Built bidirectional sync for merchants, products, manifests, negotiations, orders,
       and audit logs.
     - Built resilient Google OAuth token verification with clock skew tolerance and fast cache.

  E. AI Growth & Upsell Agent (Revenue Growth):
     - Implemented category-aware "Frequently Bought Together" bundles (e.g., MagSafe Armor
       Case + 25W Charger for smartphones, Anti-Blister Socks for shoes).
     - Allowed 1-click cart expansion with policy-validated bundle totals up to ₹2,50,000.

  F. Sarvam AI Multilingual Voice Assistant:
     - Integrated Sarvam AI APIs: Saaras v3 for Speech-to-Text and Bulbul v3 for
       Text-to-Speech across 11 Indian languages (Hindi, Tamil, Telugu, Kannada, etc.).
     - Built dedicated Voice AI studio (/voice) with live microphone waveform animation,
       transcript display, parsed intent tags, and audio playback.

  G. Proactive AI Growth Agent & 90-Day GMV Simulation:
     - Proactive background analytics for merchants (/merchant/:id/growth):
       * Cross-Sell attach rates and revenue uplift per order
       * Statistical pricing outliers using standard deviation z-scores
       * Abandoned-cart recovery nudges validated through the policy engine
       * 90-Day GMV Simulation: baseline organic vs. agent-assisted comparison chart.

  H. Protocol Interoperability & Manifest Exports:
     - Built schema.org/Product JSON-LD export (/api/export/schema-org/{id}).
     - Built Agent Commerce Protocol envelope (/api/export/acp/{id}) implementing
       ACP v0.1 draft standards for autonomous ecosystem interop (UAP, ACP, AP2, x402).

  I. Public "Agent-Ready" Certificate:
     - Built shareable merchant badge page (/merchant/:id/certificate).
     - Features animated SVG trust score ring gauge, Platinum/Gold/Silver tier badges,
       four-factor breakdown, and deterministic SHA-256 verification hash.

  J. Real-Time WebSocket Streaming & Multi-Round Counter Negotiation:
     - Created WebSocket endpoint (/ws/negotiate/{id}) streaming proposal frames,
       deliberation thinking states, and policy verdicts live.
     - Added Round 2 counter-offer decision panel in checkout (Accept, Counter, Decline).

  K. Abuse, Rate Limiting & Sub-₹500 Price Protection:
     - Dynamic price floor: `effective_min_price = min(merchant_min_price, product.price)`
       ensures catalog items priced under ₹500 (e.g. ₹418, ₹449) are never blocked.
     - Rate-limits buyer negotiations to 5 attempts per product per 10 minutes (bypassed for
       direct purchases at list price).
     - Anomaly detection blocking aggressive discount demands exceeding 50%.

  L. Unified Role Architecture & Persistent Session State:
     - Simplified role hierarchy into two clean roles: **Buyer** and **Merchant**.
     - Merged all administrative audit and manual policy approval capabilities directly into
       the Merchant workflow.
     - Added 1-click on-the-fly role switcher (`🏬 Switch to Merchant` / `🛍️ Switch to Buyer`)
       with permanent role state preserved across page reloads.
     - Added synchronous local storage hydration on line 1 of app initialization to eliminate
       1-second page flash on refresh.

  M. Accurate Local Timezone & IST Timestamps:
     - Created a specialized UTC-to-local conversion utility (`date.ts`).
     - Displays timestamps in local Indian Standard Time (12-hour AM/PM format, e.g. `01:21:59 AM`)
       across Autonomous Audit Trail, Recent Activity, My Orders, and Receipts.

  N. Policy Settings Immediate Persistence:
     - Added `flag_modified` in SQLAlchemy and Firebase RTDB synchronization to guarantee
       immediate on-disk SQLite write when updating merchant guardrails.

  O. Full-Width Expansive Modern UI:
     - Removed restrictive max-width constraints (`max-w-3xl`, `max-w-5xl`, `max-w-6xl`)
       and implemented expansive `max-w-[1720px]` layout with high-density 5-column product
       grids across all 15+ application screens.


3. COMPLETE LIST OF CORE FEATURES
--------------------------------------------------------------------------------

[FEATURE 1: PURE-PYTHON DETERMINISTIC POLICY ENGINE]
- File: backend/services/policy_engine.py
- Acts as the immutable gatekeeper for every financial action.
- Validates:
  * Maximum allowed discount percentage (max_discount)
  * Minimum floor price (min_price) with catalog price capping
  * Maximum auto-approved order cap (max_auto_order, up to ₹2,50,000)
  * Negotiation enabled toggle
- 100% deterministic, zero LLM hallucination risk.

[FEATURE 2: 1-CLICK INSTANT BUY NOW & DYNAMIC PRICE PROTECTION]
- Files: backend/services/policy_engine.py, frontend/src/pages/NegotiationCheckout.tsx
- Provides a direct `⚡ Buy Now (₹{price})` button that bypasses negotiation.
- Evaluates `effective_min_price = min(policy_min_price, product.price)` so legitimate low-price
  items (e.g. ₹418, ₹449) are processed instantly without policy rejection.

[FEATURE 3: ABUSE & ANOMALY GUARD]
- File: backend/services/policy_engine.py
- Rate-limits buyer agents to 5 negotiation attempts per product within a 10-minute window.
- Anomaly Detection: flags and blocks suspicious offers demanding >50% discount.
- All blocked attempts are immediately written to the append-only AuditLog.

[FEATURE 4: SARVAM AI MULTILINGUAL VOICE ASSISTANT]
- Files: backend/services/sarvam_service.py, backend/routers/voice.py, frontend/src/pages/VoiceAssistant.tsx
- Models:
  * Speech-to-Text: Sarvam Saaras v3
  * Text-to-Speech: Sarvam Bulbul v3
- Supports 11 Indian Languages: Hindi (hi-IN), English (en-IN), Tamil (ta-IN), Telugu (te-IN),
  Kannada (kn-IN), Malayalam (ml-IN), Marathi (mr-IN), Bengali (bn-IN), Gujarati (gu-IN),
  Punjabi (pa-IN), Odia (or-IN).

[FEATURE 5: PROACTIVE AI GROWTH AGENT & GMV SIMULATOR]
- Files: backend/services/growth_engine.py, backend/routers/growth.py, frontend/src/pages/GrowthDashboard.tsx
- Proactive intelligence module analyzing catalog data:
  * Cross-Sell Intelligence: Identifies category pairings (e.g. Smartphones + Audio at 68%
    attach rate) and calculates revenue uplift per order.
  * Category Pricing Outlier Detection: Computes median, mean, and standard deviation z-scores
    to flag overpriced/underpriced items (>1.2σ).
  * Cart Recovery Nudges: Simulates abandoned checkout recovery offers, all gated through
    the policy engine before presentation.
  * 90-Day GMV Simulation: Projects baseline organic sales vs agent-assisted revenue uplift
    with weekly Recharts breakdown.

[FEATURE 6: PROTOCOL-COMPATIBLE MANIFEST EXPORTS (ACP & SCHEMA.ORG)]
- File: backend/routers/export.py
- Answers open-ecosystem interoperability (UAP, ACP, AP2, x402):
  * /api/export/acp/{id}: Agent Commerce Protocol (ACP v0.1) envelope containing merchant
    trust ratings, discount policies, auto-order thresholds, and structured inventory.
  * /api/export/schema-org/{id}: Standardized schema.org/Product JSON-LD format for
    universal crawlers and Google Shopping.

[FEATURE 7: PUBLIC AGENT-READY CERTIFICATE]
- Files: backend/routers/certificate.py, frontend/src/pages/AgentReadyCertificate.tsx
- Shareable merchant badge page at /merchant/:id/certificate.
- Highlights:
  * Animated circular SVG ring gauge showing 0–100 score
  * Certification Tiers: Platinum (≥85), Gold (≥70), Silver (≥50), Bronze (<50)
  * Breakdown bars for Completeness, Settlement, Dispute Rate, and Freshness
  * Deterministic SHA-256 verification hash

[FEATURE 8: REAL-TIME WEBSOCKET STREAMING NEGOTIATION]
- Files: backend/routers/ws_negotiate.py, frontend/src/pages/NegotiationCheckout.tsx
- Streams live frames over WebSocket on /ws/negotiate/{product_id}:
  1. Buyer's initial offer frame
  2. Live "deliberating / thinking" pulsating indicator
  3. Merchant AI proposed counter-offer
  4. Policy engine validation verdict
- Seamless automatic fallback to REST API if WebSockets are unavailable.

[FEATURE 9: SECOND NEGOTIATION ROUND (COUNTER-OFFER)]
- Files: backend/routers/negotiate.py, frontend/src/pages/NegotiationCheckout.tsx
- Extends negotiation to multi-round agentic interaction:
  * If merchant AI counters, buyer receives a Round 2 Decision Card.
  * Options: Accept Counter (price lock), Submit Round 2 Counter-Offer, or Decline Deal.

[FEATURE 10: AI GROWTH & UPSELL AGENT (CHECKOUT BUNDLING)]
- Files: frontend/src/pages/NegotiationCheckout.tsx, frontend/src/pages/Receipt.tsx
- When a negotiation succeeds, the Upsell Agent recommends an exclusive category-aware
  bundle (Phone Case + Charger, Performance Socks, Audio Hard Case, USB-C Hub).
- 1-click cart expansion updates the total payable amount, re-validated by the policy
  engine and passed to Razorpay.

[FEATURE 11: TRUST SCORER (0–100 COMPREHENSIVE RATING)]
- File: backend/services/trust_scorer.py
- Four-dimension weighted scoring:
  * Catalog Completeness (35%)
  * Settlement Consistency (30%)
  * Dispute Rate Inverse (20%)
  * Catalog Freshness (15%)

[FEATURE 12: RAZORPAY INTEGRATION (TEST-MODE ENFORCED)]
- File: backend/services/razorpay_service.py
- Creates Razorpay orders only AFTER policy check validation.
- Verifies HMAC-SHA256 payment signatures.
- Fails closed: rejects live keys at startup to protect merchants.

[FEATURE 13: IMMUTABLE APPEND-ONLY AUDIT LOG]
- Files: backend/services/audit_service.py, frontend/src/pages/AuditLog.tsx
- Records all system, LLM, policy, and buyer events with actor attribution, input/output JSON,
  decisions (approved, blocked, info), and human-readable reasons.
- Displays timestamps in local IST 12-hour format (e.g. `01:21:59 AM`).

[FEATURE 14: UNIFIED ROLE ARCHITECTURE & PERSISTENCE]
- Files: backend/services/auth_service.py, backend/routers/auth_routes.py, frontend/src/stores/authStore.ts
- Two primary roles: **Buyer** and **Merchant**.
- 1-Click Role Switcher in the top profile menu and on access-restricted cards.
- Persistent session caching in localStorage ensuring zero role reversion on page refresh.

5. BACKEND API ENDPOINTS REFERENCE
--------------------------------------------------------------------------------
Merchants:
  POST /api/merchants                         Create merchant
  GET  /api/merchants                         List merchants
  GET  /api/merchants/{id}                    Get merchant

Manifest:
  POST /api/manifest/generate/{id}            Normalize catalog into manifest
  GET  /api/manifest/{id}                     Get manifest + products
  PUT  /api/products/{id}                     Inline edit product

Trust:
  POST /api/trust/score/{id}                  Compute trust score

Intent & Match:
  POST /api/intent                            Parse NL intent into constraints
  POST /api/match                             Rank and match products

Negotiation & Policy:
  POST /api/negotiate                         Submit negotiation offer
  POST /api/negotiate/counter/{id}            Submit Round 2 counter-offer
  WS   /ws/negotiate/{id}                     WebSocket real-time streaming
  POST /api/policy/check                      Validate offer against policy
  GET  /api/policy/{id}                       Get merchant policy rules
  PUT  /api/policy/{id}                       Update policy rules (immediate SQLite persist & RTDB sync)

AI Growth Agent:
  GET  /api/growth/{id}                       Get cross-sell, pricing outliers, GMV simulation

Sarvam AI Voice Assistant:
  GET  /api/voice/status                      Get voice service readiness and languages
  POST /api/voice/stt                         Transcribe audio file (Saaras v3)
  POST /api/voice/tts                         Convert text to speech (Bulbul v3)
  POST /api/voice/converse                    Full voice commerce pipeline

Auth & Role Management:
  POST /api/auth/register                     Sync & register user profile in RTDB (defaults to Buyer)
  GET  /api/auth/me                           Get current authenticated profile and role
  POST /api/auth/switch-role                  1-Click toggle between Buyer and Merchant roles
  POST /api/auth/apply-merchant               Buyer applies for merchant store ownership
  GET  /api/auth/application-status           Check status of merchant onboarding application
  GET  /api/admin/applications                List all pending merchant applications
  POST /api/admin/approve-merchant/{uid}      Approve store, create Merchant, elevate role
  POST /api/admin/reject-merchant/{uid}       Decline onboarding application with reason

Orders (Razorpay):
  POST /api/order/create                      Create Razorpay order (policy-gated, idempotent)
  POST /api/order/verify                      Verify payment signature
  GET  /api/orders/{id}                       Get order details
  GET  /api/orders/mine                       Buyer views own historical agent orders
  GET  /api/merchant/{id}/pending-orders      Merchant reviews high-value orders awaiting approval
  POST /api/orders/{id}/approve               Merchant manually releases order over max_auto_order
  POST /api/orders/{id}/reject                Merchant declines high-value order

Protocol Exports & Certificate:
  GET  /api/export/acp/{id}                   Export ACP v0.1 envelope
  GET  /api/export/schema-org/{id}            Export schema.org JSON-LD
  GET  /api/merchant/{id}/certificate         Public Agent-Ready Certificate

Audit & Analytics:
  GET  /api/audit                             Get full platform audit trail (local IST timestamps)
  GET  /api/audit/{id}                        Get merchant audit trail
  GET  /api/dashboard/{id}                    Get dashboard analytics
  GET  /api/firebase/status                   Check Firebase sync status
  POST /api/firebase/ping                     Ping Firebase RTDB
